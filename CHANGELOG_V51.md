# V51 — 3D/AR Capture Guide

- Removed the native Object Capture bridge/module from the Seller repository.
- Returned the Seller product flow to the normal file-based 3D/AR upload workflow.
- Added a dedicated Seller guide for iOS and Android 3D/AR capture.
- iOS guide: Reality Composer Object Capture, USDZ preservation, on-device USDZ→GLB conversion option, and real-world scale checks.
- Android guide: KIRI Engine Photo Scan / Featureless Object Scan, Measure + Rescale, GLB/USDZ export, and real-world scale checks.
- Added the guide to Seller navigation and linked it from the 3D/AR upload steps.
- No new backend service, database, storage bucket, or processing infrastructure is introduced.
